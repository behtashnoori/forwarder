# Organization PowerShell onboarding contract

Inputs are `organization_name`, unique `public_id`, administrator username and identity fields, plus optional initial experts. In one database transaction the controlled server script creates or verifies the organization, creates or unambiguously reuses users, creates one active membership per user, assigns `ORGANIZATION_ADMIN` only to the named administrator, optionally adds experts as `EXPERT`, and verifies no platform authority was granted. Repeated execution must compare existing identities and memberships, reuse only exact matches, and fail on ambiguity or conflicting ownership. Roll back the entire transaction on any failure. Platform admins are created separately with `scripts/bootstrap_platform_admin.py` using both username and numeric ID.
