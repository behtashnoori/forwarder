# Cohort adjudication instructions

This plan proves no safe multi-row cohort with the available sanitized data.
Every cohort has one member because parent IDs and evidence paths were omitted;
structural type knowledge alone cannot prove two rows share a root.

Reviewers must not treat the structural class as ownership. The plan permits no
cohort Organization assignment and leaves every decision blank and PENDING.
Two distinct reviewers, evidence, and a stable decision ID remain mandatory.
Expansion must produce one explicit row decision per stable member and retain
QUARANTINED until the complete row-level package validates. Partial expansion,
overlap, injected members, stale approvals, and target injection are rejected.

Future reduction requires a separately sanitized package containing verified
parent stable IDs. Only rows with the same exact root and compatible disposition
may then form a multi-member cohort. Even then, disposition inheritance does
not authorize Organization inheritance.
