# ایجاد مدیر اولیه شرکت

## کاربرد

این فرمان حساب مدیر اولیه را برای یک نصب مستقل و تک‌شرکتی Forwarder ایجاد می‌کند. اجرای آن فقط برای اپراتور فنی مجاز و در محیط صحیح برنامه در نظر گرفته شده است.

## فرمان

```powershell
python manage.py create-admin
```

## اطلاعات ورودی

فرمان فقط اطلاعات زیر را دریافت می‌کند:

- نام مدیر
- نام کاربری
- رمز عبور
- تکرار رمز عبور

ایمیل، شماره موبایل، شماره تلفن و نام شرکت درخواست نمی‌شوند. نقش نیز از اپراتور پرسیده نمی‌شود و حساب با نقش موجود `admin` ساخته می‌شود.

## اثر بر دیتابیس

- ساختار دیتابیس تغییر نمی‌کند.
- هیچ migration جدیدی لازم نیست.
- پس از تأیید اپراتور، یک ردیف در جدول موجود `expert_user` درج می‌شود.
- رمز عبور فقط به‌صورت hash سازگار با bcrypt موجود برنامه ذخیره می‌شود.
- مقدار فیلدهای email و phone برابر NULL باقی می‌ماند.

## محدودیت

- این حساب super-admin نیست.
- این حساب platform-admin نیست.
- این فرمان قابلیت multi-tenancy ایجاد نمی‌کند.
- هر نصب مستقل نمایندهٔ یک شرکت است و این فرمان شرکت یا tenant جدیدی نمی‌سازد.

## امنیت

- ورود رمز عبور و تکرار آن مخفی است.
- رمز عبور و hash آن هرگز چاپ نمی‌شوند.
- نام کاربری تکراری رد می‌شود و حساب موجود تغییر نمی‌کند.
- پاسخ پیش‌فرض به تأیید نهایی «خیر» است.
- فرمان باید فقط توسط اپراتور مجاز و در محیط صحیح برنامه اجرا شود.
