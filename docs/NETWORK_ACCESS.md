# دسترسی از شبکه و اینترنت

## اقدامات انجام‌شده

1. **Vite** در `vite.config.ts` با `host: "0.0.0.0"` تنظیم شده تا روی همه اینترفیس‌ها گوش دهد.
2. **فایروال ویندوز**: قانون «Vite Dev Server - Port 8080» برای پورت 8080 (ورودی TCP) اضافه شده است.
3. **آدرس API در مرورگر**: وقتی از شبکه/اینترنت اپ را باز می‌کنید، فرانت‌اند به‌صورت خودکار همان host را با پورت 5000 برای API استفاده می‌کند (دیگر خطای fetch به خاطر `127.0.0.1` نمی‌دهد).
4. **CORS بک‌اند**: در حالت development یا با `CORS_ALLOW_ALL_ORIGINS=1` هر origin مجاز است تا از اینترنت بتوانید با اپ کار کنید.

## دسترسی به اپ

- **از همان سرور**: `http://localhost:8080` یا `http://130.185.77.25:8080`
- **از شبکه/اینترنت**: `http://130.185.77.25:8080` (IP سرور را در صورت تفاوت عوض کنید)

## اگر از اینترنت وصل نمی‌شوید

احتمالاً فایروال یا روتر **بیرون از این ویندوز** پورت 8080 را بسته است. باید در همان جایی که IP سرور (مثلاً 130.185.77.25) را مدیریت می‌کنید:

- پورت **8080/TCP** را برای ورودی (Inbound) به این سرور **باز** کنید، یا
- اگر پشت NAT هستید، **Port Forwarding** پورت 8080 به IP این سرور تنظیم شود.

## باز کردن مجدد پورت در فایروال ویندوز

اگر قانون فایروال حذف شد، در PowerShell **با دسترسی Administrator** اجرا کنید:

```powershell
npm run firewall:open
```

یا مستقیم:

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/open-firewall-port.ps1
```

## اجرای سرور

```bash
npm run dev
```

بعد از بالا آمدن سرور، از مرورگر یا گوشی به `http://IP_SERVER:8080` بروید.
