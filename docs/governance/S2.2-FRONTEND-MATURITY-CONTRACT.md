# S2.2 — Frontend Maturity Contract

## Scope and target

The critical Organization Logistics Network flow is Level 4: it uses shared interaction states, Persian-first copy, responsive grid layouts, accessible names and focus-visible controls, role-aware visibility, and automated component regression tests. Backend authorization remains authoritative.

## Interaction and form contract

Existing shadcn/Radix primitives remain the UI basis. Critical async flows distinguish loading, empty, error and retry. Inputs have an accessible name; identifier fields use LTR isolation inside RTL pages; actions are disabled while submitting. User-facing API errors distinguish permission, not found, validation, conflict, network, and server conditions without exposing backend details.

## Role and information architecture

Organization users see the business action **افزودن از شبکه مرجع** within Organization Logistics Network. Platform-only reference governance remains separate. UI visibility is convenience only; the API/domain authorization boundary is unchanged.

## Deferred

No browser E2E harness was introduced: the repository has no existing Playwright/Cypress foundation, and component/integration coverage was strengthened without creating a second test program. Automated axe scanning is deferred; Testing Library semantic/accessibility checks cover the changed flow but do not constitute WCAG conformance.
