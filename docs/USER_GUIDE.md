## Getting Started

### System Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- Screen resolution: 1024x768 or higher

### Accessing the System
1. Open your web browser
2. Navigate to the system URL
3. Use your provided credentials to log in

### First Login
1. Enter your username and password
2. Click "ورود" (Login)
3. You'll be redirected to your dashboard

## Expert Console

### Dashboard Overview
The expert console dashboard provides:
- **KPI Cards**: Key performance indicators
- **Request Summary**: Status breakdown of requests
- **SLA Alerts**: Overdue or soon-to-be-due requests
- **Recent Activity**: Latest system activities

### Managing Shipment Requests

#### Viewing Requests
1. Navigate to the "درخواست‌ها" (Requests) tab
2. Use filters to narrow down results:
   - Status filter
   - Priority filter
   - Search by customer name or phone
3. Click on a request to view details

#### Request Statuses
- **جدید** (New): Newly submitted requests
- **ارجاع شده** (Assigned): Assigned to an expert
- **در حال پیگیری** (In Progress): Being processed
- **منتظر مشتری** (Waiting for Customer): Awaiting customer response
- **برنده** (Won): Successfully completed
- **باخته** (Lost): Not completed
- **مختومه** (Closed): Final status

#### Assigning Requests
1. Click on an unassigned request
2. Click "ارجاع به من" (Assign to Me)
3. The request will be assigned to you

#### Updating Request Status
1. Select a request
2. Click the appropriate status button:
   - "شروع پیگیری" (Start Processing)
   - "انتظار مشتری" (Wait for Customer)
   - "برنده" (Won)
3. Add notes if necessary

#### Adding Messages
1. Open request details
2. Go to "پیام‌ها" (Messages) tab
3. Click "پیام جدید" (New Message)
4. Select message type:
   - **یادداشت داخلی** (Internal Note): For team communication
   - **پیام مشتری** (Customer Message): For customer communication
5. Enter subject and content
6. Click "ارسال" (Send)

### SLA Management
- **سبز**: On time
- **زرد**: Due soon (within 2 hours)
- **قرمز**: Overdue

## CRM Dashboard

### Customer Management

#### Adding New Customers
1. Click "مشتری جدید" (New Customer) button
2. Fill in customer information:
   - **اطلاعات شخصی** (Personal Info):
     - First Name (نام)
     - Last Name (نام خانوادگی)
     - Email (ایمیل)
     - Phone (تلفن)
   - **اطلاعات شرکت** (Company Info):
     - Company Name (نام شرکت)
     - Industry (صنعت)
     - Company Size (اندازه شرکت)
   - **اطلاعات تماس** (Contact Info):
     - Address (آدرس)
     - City (شهر)
     - Province (استان)
3. Click "ذخیره" (Save)

#### Customer Types
- **مشتری** (Customer): Active paying customers
- **پیشنهاد** (Prospect): Potential customers
- **شریک** (Partner): Business partners
- **فروشنده** (Vendor): Suppliers

#### Customer Status
- **فعال** (Active): Currently engaged
- **غیرفعال** (Inactive): Not currently engaged
- **مسدود** (Blocked): Restricted access

### Sales Management

#### Creating Opportunities
1. Navigate to "فرصت‌های فروش" (Sales Opportunities)
2. Click "فرصت جدید" (New Opportunity)
3. Fill in opportunity details:
   - **عنوان** (Title): Opportunity name
   - **مشتری** (Customer): Select customer
   - **مرحله** (Stage): Current stage
   - **ارزش** (Value): Estimated value
   - **احتمال** (Probability): Success probability
   - **تاریخ بسته شدن** (Close Date): Expected close date
4. Click "ذخیره" (Save)

#### Opportunity Stages
- **سرنخ** (Lead): Initial contact
- **تایید شده** (Qualified): Verified potential
- **پیشنهاد** (Proposal): Proposal sent
- **مذاکره** (Negotiation): In negotiation
- **برنده** (Won): Successfully closed
- **باخته** (Lost): Not successful

### Activity Management

#### Creating Activities
1. Navigate to "فعالیت‌ها" (Activities)
2. Click "فعالیت جدید" (New Activity)
3. Select activity type:
   - **تماس** (Call): Phone calls
   - **ایمیل** (Email): Email communications
   - **جلسه** (Meeting): Face-to-face meetings
   - **وظیفه** (Task): Assigned tasks
   - **یادداشت** (Note): General notes
4. Fill in activity details:
   - **موضوع** (Subject): Activity title
   - **توضیحات** (Description): Detailed description
   - **اولویت** (Priority): High, Normal, Low
   - **تاریخ موعد** (Due Date): When to complete
5. Click "ذخیره" (Save)

#### Activity Priorities
- **فوری** (Urgent): Must be done immediately
- **بالا** (High): Important, do soon
- **عادی** (Normal): Standard priority
- **پایین** (Low): Can be done later

## Troubleshooting

### Common Issues

#### Login Problems
- **Problem**: Cannot log in
- **Solution**: 
  1. Check username and password
  2. Ensure caps lock is off
  3. Clear browser cache
  4. Contact administrator

#### Performance Issues
- **Problem**: Slow loading
- **Solution**:
  1. Check internet connection
  2. Close unnecessary browser tabs
  3. Clear browser cache
  4. Try a different browser

#### Data Not Updating
- **Problem**: Changes not saving
- **Solution**:
  1. Check internet connection
  2. Refresh the page
  3. Try again in a few minutes
  4. Contact support if problem persists
