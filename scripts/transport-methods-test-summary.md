## روش‌های حمل موجود

### روش‌های بین‌المللی (5 روش)
1. **حمل دریایی** (Sea Freight) - مناسب برای بارهای حجیم و سنگین
2. **حمل هوایی** (Air Freight) - سریع و مناسب برای بارهای فوری
3. **حمل زمینی** (Land Transport) - مناسب برای مسیرهای کوتاه و متوسط
4. **حمل ریلی** (Rail Transport) - مناسب برای بارهای حجیم و مسیرهای طولانی (2 نمونه)

### روش‌های داخلی (4 روش)
1. **حمل ریلی** (Rail Transport) - مناسب برای بارهای حجیم و مسیرهای طولانی (2 نمونه)
2. **حمل جاده‌ای** (Road Transport) - سریع و قابل اعتماد برای حمل داخلی
3. **حمل هوایی** (Air Transport) - سریع‌ترین روش برای حمل داخلی

### گزینه‌های ترجیح
1. **انتخاب مشتری** (customer_choice) - مشتری روش حمل را انتخاب می‌کند
2. **پیشنهاد فورواردر** (forwarder_suggestion) - فورواردر بهترین روش را پیشنهاد می‌دهد

## نکات مهم

### دسته‌بندی صحیح
- روش‌های حمل بر اساس نام انگلیسی دسته‌بندی می‌شوند
- برخی روش‌ها (مثل حمل ریلی) در هر دو دسته بین‌المللی و داخلی قرار می‌گیرند
- این رفتار صحیح است زیرا حمل ریلی می‌تواند برای هر دو نوع حمل استفاده شود

### ساختار پاسخ API
```json
{
  "international_methods": [...],
  "domestic_methods": [...],
  "preference_options": [...]
}
```

### فیلدهای هر روش حمل
- `id`: شناسه یکتا
- `name`: نام انگلیسی
- `name_fa`: نام فارسی
- `description`: توضیحات
